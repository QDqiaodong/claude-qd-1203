# 裁缝改衣店（tailor_shop）

全栈种子仓：Spring Boot 3.3 + Vue3(Element Plus)，docker compose 一键起。

## 题材
实体场所：服装修改店（改衣、面料、预约取衣）。

## 端口
- 前端 front：8323
- 后端 back：8423（容器内部 8080）
- MySQL：3623
- Redis：6623

## 4 个业务模块与关系面
1. **衣物台账**（garment）：登记待改衣物（西装/裙/裤/大衣），含客户、品类、材质、状态（待改/修改中/待取/已取）。
   - 关系面：① 品类必须属于字典约束；② 状态单向流转、已取不可回退；③ 编号唯一。
2. **改衣工单**（alteration）：每件衣物对应改衣项目（长短/宽窄/换拉链/换扣），含项目、报价、状态。
   - 关系面：① 必须关联一件衣物；② 报价必须 > 0；③ 未填项目禁止完成；④ 报价为 0 禁止完成。
3. **面料库存**（fabric）：名称、类别、库存、单位、安全下限。
   - 关系面：① 领用扣减库存；② 库存不足（为负）拦截领用；③ 领用后低于安全下限拦截领用。
4. **预约与取衣**（appointment）：预约时间、取衣记录（哪个客户取走哪件、取衣时间、是否付清）。
   - 关系面：① 预约必须关联有效衣物；② 取衣须衣物为「待取」且工单全部完成；③ 取衣须已付清；④ 取衣后置衣物为「已取」。

## 技术要点
- 后端统一 `ApiResponse.success(data)`，业务错误抛 `BizException("中文")` 映射 400。
- 实体字段不写 Java 初值，默认值在 Service 的 create 中给。
- 两处 `schema.sql`（`backend/src/main/resources/` 与 `mysql/`）完全一致，含中文种子与异常态种子。
- 前端主色 #9575CD（藕荷），左侧树形导航，列表行内编辑 + 抽屉明细。
- MySQL 日期算术用 `DATE_SUB(CURDATE(), INTERVAL N DAY)`。

## 启动
```
./start.sh --build
```
